# 工作区思维导图

把 DSH 桌面端的左侧栏收进顶部，并把主页面换成工作区思维导图。

## 它做什么

- 顶部导航条：新会话、会话、工作区总览、思维导图、插件、定时任务、更多。
- 主页面板 `mindmap`：根节点是「工作区」，下面按 8 个应用分组，每个应用再分成「复用 / 一次性」两个分支，项目以纯文字列出，连线是正交折线。
- 点应用块：镜头推近到该应用；点「工作区总览」或空白回到全览。
- 打开 DSH 时默认落在思维导图；点「新会话」回到会话页。

## 数据来源

第一版把当前工作区的 21 个项目、8 个应用分组内置在 `client.js` 顶部的 `APPS` / `MODS` 常量里。工作区新增项目后，需要同步改这两个常量（或等下一版接真实目录扫描）。

## 已知限制

- 不能在插件里改分组（分组为静态数据）；手动归属要在原型页或后续版本里做。
- 顶部导航条固定在 48px 高度，覆盖在应用上层；侧栏仍可用顶部「☰」按钮展开。
- 设置页、主题切换仍走原来的入口。
